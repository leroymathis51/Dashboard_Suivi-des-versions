# Dashboard de suivi des versions

Dashboard interactif de suivi de la fiabilité des versions robots VitiBot.

## Ouvrir le dashboard

[Accéder au dashboard publié](https://leroymathis51.github.io/Dashboard_Suivi-des-versions/)

## Données

Le site fonctionne actuellement en mode démonstration. Pour afficher les données réelles et maintenir automatiquement les versions, robots et parcelles à jour, renseigner l’URL du proxy sécurisé dans la balise `vitibot-api-url` de `index.html`. La clé Kibana doit rester côté serveur et ne doit jamais être enregistrée dans ce dépôt.
